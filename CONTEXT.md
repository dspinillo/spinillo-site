# spinillo-site · Contexto (linguagem ubíqua)

| Termo | Significa | No código |
|---|---|---|
| Case | Página de um trabalho contado como problema, decisão e número | `src/content/cases/` |
| Painel | Página navegável com o mercado de vagas coletado | `src/pages/painel` |
| Coleta | Um snapshot de vagas reunidas pelo coletor pessoal numa data | `data/vagas.json` |
| Campo derivado | Informação extraída da vaga que pode ser publicada (título, empresa, fonte, modelo, ferramentas, data, link) | `exportar-painel` |

## Não confundir

- **Radar de Vagas** (ferramenta open source, um case) ≠ **painel** (página deste site com os dados de mercado).

## Fora do vocabulário

- "Portfólio de projetos" no sentido de lista completa: o site mostra só casos escolhidos.
